Windows kompyuteridagi `Downloads` va `Telegram Desktop` papkalaridagi yangi fayllarni avtomatik ravishda Telegram botga yuboruvchi dastur.

Программа для автоматической отправки новых файлов из папок `Downloads` и `Telegram Desktop` на Telegram-бота в Windows.

A Windows utility that automatically sends new files from the `Downloads` and `Telegram Desktop` folders to a Telegram bot.
