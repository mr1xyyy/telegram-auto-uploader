# Telegram Auto File Uploader

Выбор языка: [O'zbekcha](README_UZ.md) | [Русский](README_RU.md) | [English](README_EN.md)

[Главный README](../README.md)

---

Программа для автоматической отправки новых файлов из папок `Downloads` и `Telegram Desktop` на Telegram-бота в Windows. Приложение работает в фоновом режиме, не отправляет файлы повторно и может автоматически запускаться при включении компьютера.

## Основные Возможности

- **Автоматический поиск:** находит файлы в папках `Downloads` и `Telegram Desktop`.
- **Умный фильтр (без повторной отправки):** запоминает уже отправленные файлы через `sent_files.json` и не отправляет их повторно.
- **Безопасный фильтр:** пропускает недокачанные файлы (`.tmp`, `.crdownload`) и опасные форматы (`.exe`, `.bat`).
- **Multithreading:** отправляет файлы параллельно и быстрее.
- **Auto-start (Автозапуск):** стабильный автозапуск через папку Windows `shell:startup`.

## Установка и Запуск (Local)

1. **Склонируйте репозиторий:**

   ```bash
   git clone <repo-url>
   cd <repo-folder>
   ```

2. **Создайте и активируйте виртуальное окружение:**

   ```bash
   python -m venv venv
   ```

   Для Windows:

   ```bash
   venv\Scripts\activate
   ```

3. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл конфигурации (`.env`):**

   В папке проекта создайте файл `.env` и добавьте:

   ```env
   BOT_TOKEN=ваш_bot_token
   CHAT_ID=ваш_chat_id
   ```

5. **Запустите скрипт:**

   ```bash
   python script.py
   ```

## Сборка .EXE, Иконка и Автозапуск

Порядок сборки программы в `.exe`, добавления иконки и настройки автозапуска:

1. **Создайте `.exe` через PyInstaller с иконкой из папки `src`:**

   ```bash
   pyinstaller --noconsole --onefile --icon=src/ikonka_nomi.ico script.py
   ```

   Примечание: вместо `src/ikonka_nomi.ico` укажите реальное имя файла иконки из папки `src`.

2. **Разместите важные файлы:**

   Переместите `script.exe` из папки `dist` в удобную постоянную папку и обязательно положите рядом файл `.env`.

3. **Добавьте программу в автозапуск через Startup:**

   - Нажмите **Win + R**.
   - Введите `shell:startup` и нажмите **Enter**.
   - Нажмите правой кнопкой по готовому файлу `script.exe` и выберите **Create shortcut** (Создать ярлык).
   - Переместите созданный ярлык в открытую папку `Startup`.

   После этого программа будет автоматически запускаться в фоне при каждом включении компьютера.
